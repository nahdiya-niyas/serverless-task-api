
# Serverless Architecture

```text
       Client / Postman
              |
              | HTTP Request
              v
      Amazon API Gateway
              |
              | Lambda Integration
              v
        AWS Lambda
        (Python 3.14)
              |
              | JSON Response
              v
       Client / Postman
```
